# Focus Quest

Трекер задач и привычек с таймером фокуса, очками и наградами. Работает в браузере и ставится на телефон как приложение.
Данные хранятся в браузере и синхронизируются между устройствами через ваш приватный репозиторий на GitHub.

**Открыть:** https://phoenix-magic.github.io/scheduleAndDiscipline-vibe-/

## Настройка

1. **Создайте приватный репозиторий для данных** на GitHub, например `my-tasks-data`. Он может быть пустым.
2. **Создайте токен:** GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: **Only select repositories** → репозиторий из шага 1.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Скопируйте токен (`github_pat_…`).
3. **Откройте приложение** по ссылке выше.
4. **Настройки → Синхронизация через GitHub:** введите свой логин, имя репозитория и токен. Поле «Файл» можно оставить как есть. Нажмите «Синхронизировать сейчас».
5. Повторите шаги 3–4 на каждом устройстве. На телефоне приложение можно добавить на главный экран через меню браузера.

Токен хранится только в браузере и отправляется только в GitHub.

### Claude (необязательно)

Нужен API-ключ с [console.anthropic.com](https://console.anthropic.com) — это отдельная оплата по факту использования, подписка claude.ai не подходит. Вставьте ключ в **Настройки → Claude** и нажмите «Проверить ключ». Названия задач и заметки при этом отправляются в Anthropic.

## Что умеет

- **Задачи** с шагами, сроками, сложностью и важностью; срочные задачи поднимаются наверх. Маленькие задачи можно объединить в одну.
- **Входящие** для быстрых записей и **Неделя** для распределения шагов по дням.
- **Сейчас** — подбор задачи под текущее настроение, случайная задача и таймер фокуса.
- **Привычки** — готовый набор простых дел по категориям плюс свои; расписание по дням недели и отдельная серия у каждой привычки.
- **Очки и награды** — очки за шаги, задачи, фокус и привычки тратятся на награды, которые вы придумываете сами. Есть достижения и серия дней.
- **Статистика** — графики и задачи, которые давно не двигаются.
- **Claude** — подбор задачи по описанию самочувствия, разбивка задачи на шаги, автозаполнение оценок и итоги недели.
- Работает без интернета, есть резервная копия в файл, светлая и тёмная тема.
